# Clique e Poesia — Um Clique, uma poesia! 📸✨

> "A gente, que ama fotografar e ama escrever, criou a Clique e Poesia!"

Site oficial e portfólio interativo da **Clique e Poesia**, construído com React, TypeScript, Tailwind CSS, Motion e Vite, otimizado para deploy instantâneo na **Vercel**.

---

## 🚀 Tecnologias

- **React 19** + **TypeScript**
- **Vite** (Build ultra-rápido)
- **Tailwind CSS v4**
- **Motion** (Animações fluidas)
- **Lucide Icons**
- **Vercel** (Hospedagem & CDN global)

---

## 🛠️ Como Rodar Localmente

1. **Instalar dependências:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse `http://localhost:3000` no seu navegador.

3. **Gerar build de produção:**
   ```bash
   npm run build
   ```

4. **Pré-visualizar o build de produção:**
   ```bash
   npm run preview
   ```

---

## 🌐 Deploy na Vercel

O projeto já inclui o arquivo `vercel.json` com roteamento configurado para SPA (Single Page Application).

1. Importe o repositório na [Vercel](https://vercel.com/new).
2. O framework preset será detectado automaticamente como **Vite**.
3. Clique em **Deploy**.
